# Bot va Userbot Tizimi

Telegram bot va userbot ikki alohida jarayon sifatida ishlaydigan, bitta shared database bilan bog'langan tizim.

## 📁 Fayl Tuzilishi

```
project/
├── database.py          # Shared database moduli
├── bot.py              # Telegram bot
├── userbot.py          # Telegram userbot
├── requirements.txt    # Python kutubxonalari
├── .env               # Muhit o'zgaruvchilari
└── README.md          # Dokumentatsiya
```

## 🚀 O'rnatish

### 1. Kutubxonalarni o'rnatish

```bash
pip install -r requirements.txt
```

### 2. .env faylini sozlash

`.env` faylida quyidagi o'zgaruvchilarni to'ldiring:

- `BOT_TOKEN` - Telegram bot token
- `SUPER_ADMIN_ID` - Super admin ID
- `PHONE` - Userbot telefon raqami
- `API_ID` - Telegram API ID
- `API_HASH` - Telegram API Hash
- `SESSION_STRING` - Userbot session string

## ▶️ Ishga Tushirish

### Bot ishga tushirish:
```bash
python bot.py
```

### Userbot ishga tushirish (alohida terminal):
```bash
python userbot.py
```

### Ikkalasini birga ishga tushirish (Linux/Mac):
```bash
python bot.py & python userbot.py &
```

### Ikkalasini birga ishga tushirish (Windows):
Ikkita alohida terminal oching va har birida ishga tushiring.

## 📊 Database Tuzilishi

Database `bot_data.db` faylida SQLite formatida saqlanadi.

### Jadvallar:

1. **admins** - Adminlar ro'yxati
2. **keywords** - Kalit so'zlar
3. **private_groups** - Shaxsiy guruhlar (har bir admin uchun bitta)
4. **search_groups** - Izlovchi guruhlar (har bir admin uchun 100 tagacha)
5. **bot_settings** - Bot sozlamalari

## 🔧 Xususiyatlar

### Bot (bot.py):
- ✅ Admin boshqaruvi (faqat super admin uchun)
- ✅ Kalit so'zlarni boshqarish
- ✅ Shaxsiy guruh qo'shish/o'chirish
- ✅ Izlovchi guruhlarni boshqarish
- ✅ Guruh xabarlarini tekshirish
- ✅ Kalit so'z topilganda xabar yuborish

### Userbot (userbot.py):
- ✅ Barcha guruhlardagi xabarlarni kuzatish
- ✅ Kalit so'z topilganda xabar yuborish
- ✅ 24/7 ishlash
- ✅ Kundalik restart (00:00 to'xtatish, 02:00 qayta ishga tushirish)

### Database (database.py):
- ✅ Shared database - Bot va Userbot bir xil databasedan foydalanadi
- ✅ Ma'lumotlar saqlanadi (bot restart qilinsa ham)
- ✅ Faqat adminlar ma'lumotlarni o'chirishi mumkin
- ✅ 1 soatlik limit izlovchi guruh qo'shishda (super admin bundan mustasno)

## 🔐 Xavfsizlik

- Token va API kalitlarni `.env` faylida saqlang
- `.env` faylini GitHub ga yuklamang
- Super admin ID ni maxfiy saqlang
- Session string ni hech kimga bermang

## 📋 Buyruqlar

### Bot buyruqlari:
- `/start` - Botni ishga tushirish
- `/id` - Guruh ID olish (guruhlarda)

### Admin imkoniyatlari:
- Kalit so'z qo'shish/o'chirish
- Shaxsiy guruh qo'shish/o'chirish
- Izlovchi guruh qo'shish/o'chirish (1 soatda 1 ta)
- Barcha ma'lumotlarni ko'rish

### Super Admin imkoniyatlari:
- Yangi admin qo'shish
- Adminni o'chirish
- Adminlar ro'yxatini ko'rish
- Har qanday admin xonasiga kirish
- Cheksiz izlovchi guruh qo'shish

## 🕐 Userbot Ish Jadvali

- **02:00** - Userbot qayta ishga tushadi
